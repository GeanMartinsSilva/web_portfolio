Política de Privacidade

Vigente desde 6 de novembro de 2026.

O Matrix Estudio é uma ferramenta particular, usada só pelo seu autor, Gean Martins Silva, para produzir e publicar vídeos nos canais do YouTube que ele mesmo administra. Esta página explica quais dados o app acessa, como eles são usados e como apagá-los.

Dados que o app acessa

Só depois da autorização do dono do canal na tela de permissão do Google, e só no canal autorizado:

  • Envio de vídeos (permissão youtube.upload): envio de vídeos e capas para o canal.
  • Leitura do canal (permissão youtube.readonly): identificação e nome do canal, lista de vídeos enviados, contagem pública de inscritos, visualizações, curtidas e comentários.
  • Leitura do YouTube Analytics (permissão yt-analytics.readonly): relatórios de desempenho do canal e dos vídeos, como visualizações, tempo assistido, retenção, origem do tráfego, termos de busca, impressões e taxa de cliques.

O app não pede acesso a e-mail, contatos, arquivos nem a qualquer outro dado da Conta do Google.

Como os dados são usados

Os dados servem só para publicar os vídeos do próprio estúdio e para mostrar ao dono do canal, no painel particular do estúdio, como cada vídeo está indo. Os dados não são vendidos, não são usados para publicidade, não são compartilhados com terceiros e não são usados para treinar modelos de inteligência artificial.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Onde os dados ficam

As autorizações (tokens) e os números coletados ficam guardados só no computador particular do estúdio, com acesso restrito ao usuário do sistema. Nada é enviado para servidores de terceiros.

Por quanto tempo e como apagar

Os números de desempenho ficam guardados enquanto o canal for acompanhado pelo estúdio, para formar o histórico de cada vídeo. A qualquer momento o dono do canal pode:

  • revogar o acesso do app na página Apps com acesso à sua conta do Google. Com isso, o app deixa de acessar o canal na hora;
  • pedir a exclusão de todos os dados guardados do canal, pelo contato abaixo. A exclusão é feita em até 7 dias.

Serviços de API do YouTube

O app usa os Serviços de API do YouTube. Valem também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Contato

Dúvidas e pedidos de exclusão: pelo e-mail de suporte que aparece na tela de permissão do Google ao autorizar o Matrix Estudio.

Mudanças nesta política

Qualquer mudança aparece nesta página, com a nova data de vigência.
